# ECC Continuous Learning Rule (Автосохранение повторяющихся пайплайнов)

При повторении однотипных многошаговых задач на этой станции:
- сборка и разбор сценариев (`.kitsp`, `LISHNIE_Mon`),
- выгрузка и рендер отчётов (OASIS, PDF/Markdown),
- настройка и диагностика роутеров (`:3001`, `:3002`, `free-coding-models`),
- сборка и деплой маркетинговых проектов (`BAREL`, `MARKETING_ENGINE`, `switch_tool.ps1`),

агент должен:
1. Завершить текущую задачу без лишнего шума.
2. В конце ответа кратко предложить сохранить отработанный пайплайн как локальный скилл в `F:\AI_STACK\catalogs\custom-skills\<имя-скилла>\SKILL.md`.
3. Создавать файл скилла только после подтверждения или прямого запроса пользователя.
